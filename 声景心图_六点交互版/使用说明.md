# 声景心图 · 六点交互版 使用说明

## 一、文件夹里有什么

- `index.html`：主地图的入口页（和 `声景心图_交互地图.html` 内容相同），部署到服务器后直接访问域名根目录即可。
- `声景心图_交互地图.html`：主地图，已改为 6 个点位。悬停/点击圆点出卡片，点空白处、×、Esc 关闭。
- `soundscape-detail.html`：二维码扫进去的声景详情页，包含自动播放音乐、进度、循环、图片滑动、环境介绍、感受记录。
- `audio/1.mp3` ~ `audio/6.mp3`：已放入你提供的 6 段音乐/环境声。
- `detail-images/1-1.jpg` ~ `6-3.jpg`：已放入你提供的 18 张照片。
- `启动课堂演示.bat`：一键启动本地服务器，适合上课拷到教室电脑用。
- `课堂演示_启动服务器.ps1`：`.bat` 调用的服务器脚本，一般不用单独点。
- `声景心图_交互地图_原始备份.html`：修改前的原始地图备份。

## 二、怎么打开

### 场景 A：只在教室电脑/投影上展示，不要求手机扫码
直接双击 `index.html` 或 `声景心图_交互地图.html`。
卡片、唱片播放器、详情页、图片、音频都能用；二维码可以点击在电脑上预览，但手机扫不了。

### 场景 B：上课时要用手机扫码（推荐）
把整个文件夹拷到教室电脑，双击 **`启动课堂演示.bat`**。
它会自动：

1. 启动一个本地网页服务器；
2. 在浏览器打开 `http://教室电脑局域网IP:8000/`；
3. 在窗口里显示手机扫码地址。

手机连**同一个 WiFi**，打开地图卡片扫二维码即可。
第一次运行如果 Windows 防火墙弹窗，选“允许访问（专用网络）”。

> 教室电脑如果禁止运行 .bat/.ps1，就用下面的“正式发布”方式，提前把整个文件夹上传到 Netlify/GitHub Pages，课上直接打开公网网址。

### 电脑本地预览（file://）
双击 `声景心图_交互地图.html`。卡片、唱片播放器、详情页跳转都能用。
但**本地 `file://` 打开的二维码，手机扫了打不开**，因为二维码里是电脑本地路径。

### 手机扫码测试（同一 WiFi，最快）
1. 确保 `index.html`、`soundscape-detail.html`、`audio/`、`detail-images/` 都在同一个文件夹。
2. 直接双击 **`启动课堂演示.bat`**。  
   如果 .bat 不方便运行，再在这个文件夹打开 PowerShell，运行：

```powershell
& "C:\Users\Lenovo\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe" -m http.server 8000 --bind 0.0.0.0
```

如果电脑装过 Python，也可以直接运行：

```powershell
python -m http.server 8000 --bind 0.0.0.0
```

3. 另开一个 PowerShell，运行 `ipconfig`，找到“无线局域网适配器 WLAN”下的 **IPv4 地址**，例如 `192.168.1.23`。
4. 电脑浏览器打开：

```text
http://192.168.1.23:8000/
```

5. 手机连**同一个 WiFi**，点开地图卡片，扫二维码。
   二维码会自动是 `http://192.168.1.23:8000/soundscape-detail.html?point=1`。
6. 如果手机打不开：Windows 防火墙弹窗要允许 Python 访问“专用网络”；路由器不能开启“AP 隔离”；服务器窗口运行期间不要关闭。

> 注意：电脑上要用局域网 IP 打开，不要用 `127.0.0.1` 或 `localhost`。否则二维码会编码成 `127.0.0.1`，手机扫了会指向手机自己。

### 正式发布（推荐，任何网络都能扫）
任选一种：

**Netlify Drop（最简单）**
1. 打开 `https://app.netlify.com/drop`。
2. 把整个文件夹（不是只拖 HTML）拖进去。
3. 等待生成网址，例如 `https://xxx.netlify.app/`。
4. 用这个网址打开地图，卡片二维码会自动变成公网地址。

**GitHub Pages**
1. 新建 GitHub 仓库，把整个文件夹上传。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch` → `main` / `root` → Save。
3. 等 1–2 分钟，得到 `https://用户名.github.io/仓库名/`。
4. 打开这个地址，扫码即可。

**学校服务器**
把整个文件夹上传到公开网站目录，保证 `https://你的域名/.../index.html` 能访问；二维码会自动使用该域名。

## 三、二维码是怎么实现的

主地图里内嵌了 `qrcode-generator`，打开卡片时自动生成二维码：

```js
const url = new URL("soundscape-detail.html?point=" + point.id, location.href).href;
const qr = qrcode(0, "M");
qr.addData(url);
qr.make();
box.innerHTML = qr.createSvgTag(4, 3);
```

所以：

- 不需要提前做 5 张二维码图片；
- 部署到哪个域名，二维码就自动指向哪个域名；
- 每个点位通过 `?point=1` ~ `?point=6` 打开详情页的不同内容；
- 二维码也可以点击，先在电脑上预览详情页。

> 如果最终要**印在纸上**，先把网页部署好，再用草料二维码/微信二维码，把
> `https://你的域名/soundscape-detail.html?point=1` 生成静态二维码图片即可。

## 四、详情页音乐自动播放说明

- 进入详情页会**尝试自动播放**。
- 手机浏览器/微信内置浏览器通常会拦截“带声音的自动播放”，这是浏览器策略，不是代码错误。
- 如果被拦截，页面会提示“点击唱片或播放键开始”；点一下即可。
- 播放完会暂停，进度条保留，可以再点播放；勾选“循环播放”可以循环。
- 卡片右上角的唱片播放器**不会自动播放**，必须点击；播放一遍后停止，唱片停止转动。

## 五、需要准备哪些文件

### 1. 每个点位一段音频（6 段）
建议 MP3，44.1kHz，128–192kbps；也可以直接用 WAV。
替换 `audio/1.mp3` ~ `audio/6.mp3`，或在主地图 `POINTS` 和详情页 `DETAIL` 里改 `audio` 路径。

### 2. 每个点位 3 张图片（共 18 张）
替换 `detail-images/1-1.jpg` ~ `6-3.jpg`。
卡片上的照片默认取每个点位的第一张；也可以单独改 `POINTS` 里的 `photo`。

### 3. 文字
- 主地图卡片文字：编辑 `声景心图_交互地图.html` 里的 `const POINTS = [...]`，改 `title/place/desc/feel/music`。
- 详情页文字：编辑 `soundscape-detail.html` 里的 `const DETAIL = {...}`，改 `intro/music/quotes/images`。

### 4. 发布地址
把整个文件夹上传后，得到公开网址。二维码会自动使用这个网址。

## 七、扫码检查清单与常见问题

### 检查清单
- 电脑浏览器打开的是 `http://局域网IP:8000/` 或公网 HTTPS 地址，不是 `file:///C:/...`。
- 卡片上的二维码下方显示“扫码 / 点击预览”（公网），不是“部署后可扫”。
- 手机和电脑在同一 WiFi（局域网测试），或手机用 4G/5G（公网测试）。
- 点开二维码进入详情页后，图片能加载、音乐能播放。
- 用微信扫一次、手机相机扫一次；iPhone 和安卓各测一次。

### 二维码扫了打不开
- 看二维码内容是不是 `file:///C:/...`：是的话说明还在本地双击打开，必须用 HTTP/HTTPS。
- 局域网：IP 写错、服务器没运行、防火墙拦截、路由器 AP 隔离。
- 公网：链接写错、页面没上传完整、详情页文件名大小写不一致。

### 详情页 404
确认 `soundscape-detail.html` 和 `index.html` 在**同一层目录**，`audio/`、`detail-images/` 文件夹也一起上传。

### 没有声音
- 手机浏览器拦截了自动播放：点一下页面里的播放键。
- 检查 `audio/1.mp3` 是否存在；用浏览器开发者工具 Network 看是否 404。
- 换成 MP3 时，记得同步修改 `POINTS` 和 `DETAIL` 里的 `audio` 路径。

### 二维码太小/太密
打印尺寸建议不小于 2.5cm × 2.5cm；用短域名；二维码四周留白。
